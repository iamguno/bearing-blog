# bearing-blog

로비아테크 베어링 블로그예요. 2026년 10월 30일에 정식으로 열었어요.

- 주소: https://blog.roviatech.co.kr/ (예전 주소 iamguno.github.io/bearing-blog/는 새 주소로 넘어가요)
- 검색엔진이 읽을 수 있게 열어 두었어요(robots.txt, sitemap.xml). 다시 미리보기로 돌리려면 `tools/build_site.py`의 `SITE_OPEN`을 `False`로 바꿔요.
- 페이지는 원고(md)를 `tools/build_site.py`로 바꿔 만들어요: `python3 tools/build_site.py <원고 md 폴더> .`
- 글은 원고 폴더에, 소개·문의·개인정보 처리방침은 원고 폴더의 `고정 페이지`에 md로 써요.
